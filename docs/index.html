FAQ

常见问题

这个软件是完全免费的吗？需要自己买 API Key 吗？

软件本身采用 MIT 开源协议完全免费。Windows 一键安装包已内置 OurFreeModel 免费模型池，不买 API Key 也能开箱直接聊；如果你想获得更稳定的旗舰模型、联网搜索或专属音色克隆，可随时在设置中填入 DeepSeek 官方或硅基流动等第三方 Key。

我的聊天记录、人格设定和参考音频会上传到作者服务器吗？

不会。本软件没有作者自建后端服务器，所有聊天记录、Raw RAG 记忆切片、人格问卷与克隆音频素材均 100% 存储在你自己的本机浏览器 IndexedDB 中，对话请求仅直接发往你选择的模型服务商。

Windows 安装包需要我提前安装 Node.js 或 Python 吗？

不需要。v0.1.5 安装包内部已经自带精简私有 Node.js 运行时，不污染你的系统环境变量，也不需要管理员权限，随时可以在 Windows「应用和功能」中一键干净卸载。

可以在手机或平板（iPad / 安卓 Pad）上使用吗？

可以。v0.1.5 已完成手机端与平板竖横屏的全套响应式适配（抽屉侧边栏、底部 Sheet 弹窗、安全区与防缩放表单），在局域网或静态托管部署后均可流畅使用。
